# Тест 5 Нормализация (1NF–3NF, BCNF)

## 1. Почему таблица books(book_id, title, author_name, author_birthdate, genre) считается ненормализованной?
- Повторяются данные автора в каждой строке
- Все поля атомарны
- book_id не является ключом
- Нет возможности добавить несколько жанров


## 2. Какая аномалия проявляется, если нельзя добавить автора без добавления книги?
- Аномалия вставки

## 3. Какое требование относится к 1NF?
- Атомарность значений

## 4. В таблице (book_id, author_id, author_name, author_birthdate) какой признак указывает на нарушение 3NF?
- author_name зависит от author_id

## 5. Какой тип зависимости нарушает 2NF?
- Частичная зависимость от составного ключа

## 6. Выберете нормальную форму, в которой не должно быть транзитивных зависимостей
- 3NF

## 8. BCNF жёстче, чем 3NF, потому что...

> Переменная отношения находится в нормальной форме Бойса-Кодда тогда и только тогда, когда детерминанты всех её функциональных зависимостей являются потенциальными ключами

Все детерминанты должны быть ключами

## 9. Какое действие выполняет оператор ALTER TABLE?
- Изменяет структуру таблицы

## 10. Укажите один из признаков over-normalization
- Данные слишком разбиты на мелкие таблицы

## 11. Соотнесите аномалии с примерами.
- Аномалия вставки Нельзя добавить автора без книги
- Аномалия обновления В одном месте имя автора изменили, в другом - нет
- Аномалия удаления Удаляем последнюю книгу - теряется автор

## 12. Какое требование относится к 2NF?
- Отсутствие частичных зависимостей

## 13. Что является основной причиной дублирования жанров в ненормализованной таблице книг?
- Жанр хранится как текст, а не внешним ключом

## 14. Укажите номер нормальной формы, в которой устраняется частичная зависимость.
-  2NF
