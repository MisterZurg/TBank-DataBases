# Тест 6 Реляционная математика (введение)

## 1. Какая операция реляционной алгебры соответствует условию в SQL конструкции WHERE?
- Селекция

## 2. Какая операция реляционной алгебры соответствует выбору только нужных столбцов в SQL?
- Проекция

## 3. Что из перечисленного является эквивалентом операции объединения в реляционной алгебре?
- UNION

## 4. Какой SQL оператор возвращает дубликаты, в отличие от UNION?
- UNION ALL


## 5. Укажите SQL эквивалент операции разности (A - B) в реляционной алгебре.
EXCEPT

## 6. Введите название операции реляционной алгебры, которая соответствует SQL INTERSECT.
- пересечение

## 7. Что представляет собой декартово произведение в SQL?
- CROSS JOIN

## 8. Какие из нижеперечисленных операций являются базовыми для реляционной алгебры?
- Селекция
- Разность
- Проекция

## 9. Что происходит при нарушении CHECK constraint в SQL?
- Запрос отклоняется

## 10. Для чего нужна реляционная алгебра при работе с SQL?
- Для понимания эквивалентных преобразований запросов

## 11. Какой вариант верно описывает ON CONFLICT в PostgreSQL?
- Механизм обработки конфликтов при вставке

## 12. Сопоставьте операции в реляционной алгебре и их аналоги в SQL.
Селекция WHERE
Проекция SELECT
Разность EXCEPT
Пересечение HAVING
Объединение UNION


## 13. Какая из диаграмм Венна соответствует операции EXCEPT?
- Левая область без пересечения
