# Тест 7 JOINs
## 1. Какой результат вернёт INNER JOIN?

- Строки, которые есть в обеих таблицах


## 2. Какие строки попадут в результат LEFT JOIN?

- Все строки из левой таблицы и совпадающие из правой

## 3. Какой подзапрос является коррелированным?

- Подзапрос, использующий колонку внешнего запрос

## 4. Что лучше использовать, если нужно выбрать второго по популярности автора?

- Оконную функцию RANK()

## 5. В каком случае лучше использовать подзапрос в FROM?
- Когда требуется выбрать все строки из двух таблиц
- Когда требуется агрегировать данные перед их соединением

## 6. Какие варианты верны для подзапросов в WHERE?

- Могут использовать оператор IN
- Могут возвращать несколько значений
